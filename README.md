# 🐦 Mercadito Aviario

Mercadito Aviario is a full-stack web application designed to simulate a small marketplace system for aviary-related products. The platform allows users to browse products, manage inventory, and interact with backend data through a structured web interface.

This project demonstrates full-stack architecture using a .NET backend and a dynamic frontend, highlighting API integration, database interaction, and modular web development practices.

---

Mercadito Aviario was built to practice and demonstrate:

## 🏗️ Architecture Overview

The application follows a layered structure:
* /Controllers → API endpoints and request handling
* /Models → Data models and entities
* /Views → UI rendering
* /Database → SQL schema and configuration

The backend handles business logic and database interaction, while the frontend renders product data and interacts with backend routes.

## ⚙️ How to Run Locally

1. Clone the repository: `git clone https://github.com/Rivan17RS/MercaditoAviario.git`
2. Open the solution in Visual Studio.
3. Configure your database connection string in `appsettings.json` (or Web.config).
4. Run database migrations (if applicable).
5. Start the application using IIS Express or `dotnet run`.
6. Navigate to: `https://localhost:<port>`
